# Glossary

| Term | Meaning |
|---|---|
| **Bastion** | The single SSH entry point to the server network, `bastion.acme.internal`. |
| **DRP** | Disaster recovery plan: how we bring services back after a major failure. See the [restore procedure](procedures/restore.md). |
| **On-call** | The person reachable outside business hours. See [on-call](team/on-call.md). |
| **P1** | Highest incident priority: a service is down for everyone. See [incident](procedures/incident.md). |
| **PVE** | Proxmox Virtual Environment, our hypervisor. See [[proxmox]]. |
| **VLAN** | Virtual network segment. See [VLANs](network/vlans.md). |
